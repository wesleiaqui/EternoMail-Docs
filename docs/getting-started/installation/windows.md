# Windows 

## Installer

1. Download the latest installer from the [Eterno Mail releases page](https://github.com/wesleiaqui/EternoMail/releases/latest):
    - amd64: `Eterno-Mail-windows-setup-amd64.exe`
    - arm64: `Eterno-Mail-windows-setup-arm64.exe`
2. Run the installer
3. Click on "More Info" in the SmartScreen dialog and then click "Run Anyway"
4. Eterno Mail should now be available from the Start menu.


## Portable

1. Download the portable executable from the [Eterno Mail releases page](https://github.com/wesleiaqui/EternoMail/releases/latest):
    - amd64: `Eterno-Mail-windows-amd64.exe`
    - arm64: `Eterno-Mail-windows-arm64.exe`
2. Move executable to a safe place of choice, create a shortcut to put on your taskbar or start menu and then run the executable
3. Click on "More Info" in the SmartScreen dialog and then click "Run Anyway"
4. Eterno Mail will launch.

## WebView2 Runtime

Eterno Mail requires the Microsoft Edge WebView2 Runtime. On Windows 11 and current Windows 10 updates, this is normally pre-installed. If needed, download it from [Microsoft](https://developer.microsoft.com/en-us/microsoft-edge/webview2/).

## Package managers

No community package manager distribution is currently maintained for Eterno Mail. Use the official installer or portable executable above.
